# EcoSort — Waste Sorting Guide

EcoSort is a responsive web application that helps users identify different types of waste and understand how to dispose of them responsibly. It provides a searchable waste directory, category-based filters, disposal instructions, and practical eco-friendly tips to encourage sustainable living.

## Features

- **Waste Directory:** Explore different waste items and their disposal methods.
- **Search Functionality:** Quickly find waste items using keywords.
- **Category Filters:** Browse recyclable, organic, hazardous, general, and electronic waste.
- **Disposal Instructions:** Learn recommended steps for handling different waste materials.
- **Waste Sorting Guide:** Understand basic waste segregation practices.
- **Eco-Friendly Tips:** Discover simple ways to reduce waste and support the environment.
- **Interactive Interface:** View additional information through modal dialogs.
- **Responsive Design:** Works across desktop, tablet, and mobile devices.
- **Suggestion Form:** Submit waste-related suggestions through the front-end interface.

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ecosort.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd ecosort
```

### 3. Run the Website

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

Note: Tailwind CSS is loaded through its CDN, so an internet connection is required for the styling to load correctly.

## How It Works

1. Browse the waste directory.
2. Search for a specific waste item or select a category.
3. Open an item to view its disposal instructions.
4. Follow the waste-sorting guide and eco-friendly tips.
5. Explore ways to improve everyday waste management habits.
